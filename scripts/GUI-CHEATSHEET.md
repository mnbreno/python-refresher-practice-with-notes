# Python Calculator GUI Cheat Sheet

| Input | Action |
| --- | --- |
| `0` to `9` | Enter a digit |
| `.` | Start or continue a decimal number |
| `+`, `-`, `*`, `/` | Choose an operation |
| `Enter` | Calculate |
| `Backspace` | Delete the last displayed character |
| `Escape` or `C` | Clear the current calculation |
| `DEL` button | Delete the last displayed character |

The keyboard bindings work while the calculator window is active. The mouse buttons remain available for every action.
